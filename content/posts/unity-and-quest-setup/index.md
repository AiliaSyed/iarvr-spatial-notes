## What the lab covers

The first lab introduces Unity's Scene, Hierarchy, Inspector, GameObjects, Transforms, Prefabs, and C# scripts. It also covers preparing a Quest-compatible Unity project.

## Setup checklist

- [ ] Install the course Unity editor version (`6000.3.26f1`) and Android Build Support.
- [ ] Prepare a new Unity 3D project.
- [ ] Configure the XR packages required by the course project.
- [ ] Enable developer mode on the Meta Quest 3S.
- [ ] Test a scene on the actual headset.

## Notes to document during implementation

Record the Unity and XR SDK versions, the headset deployment process, encountered errors, and screenshots of a successful build. This entry is a **preparation checklist**, not a claim that setup has been completed.
